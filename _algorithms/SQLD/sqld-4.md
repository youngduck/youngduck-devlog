## 4.1 서브쿼리

- 서브쿼리는 반드시 괄호로 감싸서 표현

- 들어가는 위치에 따른 구분, **스인중**

| 종류            | 설명                                                  |
| --------------- | ----------------------------------------------------- |
| 스칼라 서브쿼리 | SELECT문의 컬럼 입력 위치에 존재                      |
| 인라인 뷰       | FROM절의 테이블 입력 위치에 존재                      |
| 중첩 서브쿼리   | WHERE절, HAVING절의 컬럼 또는 테이블 입력 위치에 존재 |

- 메인쿼리의 컬럼 사용 여부에 따른 구분, **연비**

| 종류            | 설명                                            |
| --------------- | ----------------------------------------------- |
| 연관 서브쿼리   | 서브쿼리가 메인쿼리의 컬럼을 사용하는 경우      |
| 비연관 서브쿼리 | 서브쿼리가 메인쿼리의 컬럼을 사용하지 않는 경우 |
